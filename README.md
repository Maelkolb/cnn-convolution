# Convolution: ein Neuron wandert über das Bild

Interaktive Folie zur Sitzung „Deep Learning“ (Einführung in KI für DH, WiSe 2026/27).

Ein 3 × 3-Filter wandert über ein Bild mit 6 × 6 Feldern; rechts steht die Rechnung für das aktuelle Fenster.

- **Bild:** zwischen **L** und **T** umschalten (auch Tasten `L` und `T`); einzelne Felder lassen sich anklicken.
- **Filter:** senkrecht oder waagrecht; einzelne Gewichte lassen sich anklicken.
- **Fenster bewegen:** Maus über die Feature Map, Pfeiltasten oder „Wandern lassen“ (Leertaste).

Eine einzige Datei (`index.html`), keine Abhängigkeiten außer der Schrift Inter von Google Fonts.
